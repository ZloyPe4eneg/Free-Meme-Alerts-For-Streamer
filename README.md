# FreeMemeAlerts

Бесплатные мем-алерты для стрима. Зрители выбирают мем со звуком и отправляют его прямо в эфир — без доната, регистрации и загрузки файлов. Мемы подтягиваются из открытой библиотеки [Coub](https://coub.com), поэтому ничего не нужно заливать самому.

## Возможности

**Зритель**
- поиск мемов по Coub, лента популярного, быстрые теги;
- вставка ссылки вида `coub.com/view/…`;
- предпросмотр со звуком перед отправкой;
- ник и короткое сообщение к мему.

**Стример**
- панель управления без регистрации, вход только по паролю;
- оверлей работает только на устройствах, которые стример разрешил сам;
- фильтр контента 18+ и премодерация;
- кулдаун для зрителей и ограничение длины мема;
- громкость, размер мема, случайное место на экране или показ по центру;
- пропуск текущего мема, очистка очереди, повтор из истории, тестовый алерт.

**Оверлей для OBS**
- прозрачная страница, мемы играют по очереди со звуком;
- каждый мем проигрывается один раз и исчезает;
- подпись с ником и сообщением отправителя (можно отключить).

## Быстрый старт

Нужен только [Node.js](https://nodejs.org) версии 18 или новее. Зависимостей нет, `npm install` не требуется.

```bash
git clone https://github.com/ZloyPe4eneg/Free-Meme-Alerts-For-Streamer.git
```

```bash
cd Free-Meme-Alerts-For-Streamer
```

```bash
node server.js
```

Откройте <http://localhost:3000>.

## Как пользоваться

### 1. Создайте канал

На главной странице введите название, придумайте пароль (не короче 8 символов) и нажмите «Создать канал». Откроется панель стримера.

Запомните пароль: панель открывается только по нему. Сменить или восстановить пароль нельзя — если он потерян, создайте новый канал.

В панели две ссылки:

| Ссылка | Кому | Зачем |
| --- | --- | --- |
| Для зрителей (`/c/<id>`) | всем | страница выбора и отправки мема |
| Оверлей (`/overlay/<id>?key=…`) | только вам | источник для OBS |

Панель стримера находится по адресу `/dashboard/<id>` — с любого устройства она попросит пароль. Вход запоминается в браузере на 30 дней, кнопка «Выйти» завершает его раньше.

### 2. Добавьте оверлей в OBS

1. Источники → «+» → **Браузер**.
2. В поле URL вставьте ссылку оверлея из панели.
3. Ширина `1920`, высота `1080` (или размер вашей сцены).
4. Включите «Управлять аудио через OBS», если хотите регулировать звук мемов в микшере.
5. В источнике появится четырёхзначный код, а в панели стримера — запрос с тем же кодом. Нажмите «Разрешить». Это нужно один раз для каждого устройства.
6. В панели нажмите «Тестовый алерт» — мем должен появиться в OBS. Статус вверху панели сменится на «Оверлей подключён».

Мем занимает случайное место в пределах источника, поэтому размером и положением источника в OBS можно ограничить область, где появляются мемы.

Если ссылка оверлея попала к посторонним (например, засветилась на стриме), она им ничего не даст: без вашего разрешения оверлей не заработает. Чужие запросы отклоняйте, а кнопкой «Сбросить доступ оверлея» можно выпустить новую ссылку — старая и все выданные разрешения перестанут действовать.

### 3. Дайте ссылку зрителям

Киньте ссылку для зрителей в чат или описание стрима. Зрители могут отправлять мемы, только пока оверлей открыт, то есть пока идёт стрим.

### Настройки канала

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| Принимать мемы от зрителей | быстрая пауза приёма | включено |
| Премодерация | мемы ждут одобрения в панели | выключено |
| Показывать ник и сообщение | подпись под мемом | включено |
| Случайное место мема | иначе мем показывается по центру | включено |
| Кулдаун | пауза между мемами одного зрителя, 0–3600 сек | 30 сек |
| Максимальная длина мема | ролик длиннее обрывается, 3–60 сек | 15 сек |
| Громкость | 0–100% | 70% |
| Размер мема | 15–90% окна оверлея | 40% |

## Фильтр 18+

Правила Twitch и других площадок запрещают показывать порнографию и откровенный контент. Фильтр включён всегда, отключить его нельзя.

Как он работает:

- **Мемы.** Скрываются ролики, у которых в названии, тегах или имени канала автора есть слова из списка 18+ (на русском и английском: `nsfw`, `erotic`, `эротика`, `порно`, `hentai`, `18+` и другие), а также ролики с метками «18+» самого Coub.
- **Поиск.** Запросы с такими словами отклоняются сразу.
- **Отправка.** Перед показом сервер заново запрашивает мем у Coub и проверяет его — обойти фильтр прямой ссылкой нельзя.

Ограничение: фильтр видит только подписи, а не само видео. Если автор ролика не поставил ни одного «взрослого» тега, такой ролик пройдёт. Поэтому на стриме лучше включать **премодерацию** — тогда каждый мем вы видите до эфира.

Список слов находится в `server.js` (константы `ADULT_PREFIXES` и `ADULT_WORDS`) — его можно дополнить.

## Настройка сервера

Сайту нужен работающий сервер на Node.js: он хранит очередь мемов, проверяет пароли и передаёт события в оверлей. Настройки задаются переменными окружения — скопируйте `.env.example` в `.env`, заполните значения и запустите:

```bash
node --env-file=.env server.js
```

Флаг `--env-file` работает в Node.js 20.6+. Если перед сервером стоит прокси, включите на нём HTTPS и отключите буферизацию ответа для `/api/` — иначе события не дойдут до оверлея.

### Переменные окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `PORT` | порт сервера | `3000` |
| `SERVER_SECRET` | секрет, которым подписаны пароли, сессии и ссылки оверлея | создаётся в `data/secret.txt` |
| `TRUST_PROXY` | `1`, если сервер стоит за прокси: IP зрителя берётся из `X-Forwarded-For` | выключено |
| `DATA_DIR` | папка для секрета и настроек каналов | `./data` |

Задайте `SERVER_SECRET` постоянным: при его смене все пароли и ссылки перестанут работать. Настройки канала дополнительно хранятся в браузере стримера и восстанавливаются, если сервер их потерял.

## Безопасность

- **Панель стримера** открывается только по паролю. После входа сервер выдаёт сессию в cookie с флагами `HttpOnly` и `SameSite=Strict`: скрипты страницы её не видят, чужие сайты не могут ею воспользоваться. Ключей доступа в адресах и в хранилище браузера нет.
- **Пароли не хранятся.** Адрес канала содержит отпечаток пароля, подписанный секретом сервера: по адресу пароль подобрать нельзя, а серверу не нужна база паролей. Поэтому пароль нельзя сменить — только создать новый канал.
- **Перебор пароля ограничен:** 10 попыток в минуту с одного IP и 20 неверных попыток на канал за 10 минут.
- **Оверлей** требует и действующую ссылку, и разрешение стримера для конкретного устройства. Разрешение хранится в браузере этого устройства. После отказа устройство блокируется на 10 минут. «Сбросить доступ оверлея» делает недействительными старую ссылку и все разрешения.
- **API-ключей в проекте нет.** Поиск мемов работает через открытый API Coub без ключа.
- **Единственный секрет** — `SERVER_SECRET` (или файл `data/secret.txt`). Тот, кто его знает, может управлять любым каналом. Папка `data/` и файлы `.env` исключены из репозитория через `.gitignore` — не добавляйте их вручную.
- Адреса видео и звука сервер получает только от Coub: зритель не может подсунуть свою ссылку.
- Ник, сообщение и названия мемов выводятся как текст, без HTML.
- В интернете сайт должен работать по HTTPS: иначе пароль и сессия передаются открыто.

## Как устроено

```
server.js             HTTP-сервер: API, доступ, фильтр 18+, поиск по Coub, события
public/index.html     главная: создание канала
public/dashboard.html панель стримера
public/viewer.html    страница зрителя
public/overlay.html   оверлей для OBS
public/common.js      общие функции страниц
public/style.css      оформление
.env.example          пример переменных окружения
```

События доставляются через Server-Sent Events: панель и оверлей держат одно соединение с сервером, WebSocket и сторонние сервисы не нужны.

### API

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/memes?q=&page=` | поиск мемов; без `q` — популярное |
| `POST /api/channels` | создать канал (название и пароль) |
| `GET /api/channels/:id` | публичные сведения о канале |
| `POST /api/channels/:id/send` | отправить мем (зритель) |
| `POST /api/channels/:id/login` | вход стримера по паролю |
| `POST /api/channels/:id/logout` | выход |
| `POST /api/channels/:id/admin` | действия стримера, нужна сессия |
| `GET /api/channels/:id/events` | поток событий панели, нужна сессия |
| `GET /api/channels/:id/overlay-events?key=&ticket=` | поток событий оверлея |

## Частые вопросы

**Мем не появляется в OBS.** Проверьте, что в панели горит «Оверлей подключён». Если в источнике виден код — разрешите устройство в панели. Если нет ни кода, ни мемов — скопируйте ссылку оверлея заново и вставьте в источник «Браузер».

**OBS снова просит разрешение.** Разрешение хранится в данных браузера OBS. Оно пропадает, если очистить кэш источника, переустановить OBS или сбросить доступ оверлея — просто разрешите устройство ещё раз.

**Нет звука.** В OBS откройте свойства источника и проверьте громкость в микшере. В обычном браузере звук блокируется до первого клика по странице — в OBS такого ограничения нет.

**Зритель видит «Стример сейчас не в эфире».** Оверлей не открыт или не разрешён. Запустите OBS со сценой, где есть источник оверлея.

**Поиск пишет «Такой запрос запрещён».** В запросе есть слово из списка 18+. См. раздел [Фильтр 18+](#фильтр-18).

**Как открыть панель с другого устройства.** Откройте `/dashboard/<id>` (тот же `<id>`, что в ссылке для зрителей) и введите пароль.

**Забыл пароль.** Восстановить его нельзя: сервер паролей не хранит. Создайте новый канал и дайте зрителям новую ссылку.

**Мем слишком быстро исчезает.** Мем проигрывается один раз — столько, сколько длится сам ролик на Coub. Короткие ролики идут пару секунд.
