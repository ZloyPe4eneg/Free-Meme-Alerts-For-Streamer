# FreeMemeAlerts

Бесплатные мем-алерты для стрима. Зрители выбирают мем со звуком и отправляют его прямо в эфир — без доната, регистрации и загрузки файлов. Мемы подтягиваются из открытой библиотеки [Coub](https://coub.com), поэтому ничего не нужно заливать самому.

## Возможности

- **Для зрителя:** поиск по Coub, лента популярного, вставка ссылки `coub.com/view/…`, предпросмотр со звуком, ник и сообщение.
- **Для стримера:** панель управления без регистрации, премодерация, кулдаун, ограничение длины мема, громкость, пропуск, очистка очереди, повтор из истории, тестовый алерт.
- **Оверлей для OBS:** прозрачная страница, мемы играют по очереди со звуком.
- Мемы 18+ (по метке Coub) отфильтровываются. Адреса видео и звука сервер берёт только с Coub — зритель не может подсунуть свою ссылку.
- Ноль зависимостей: только Node.js 18+.

## Запуск

```bash
node server.js
```

Откройте <http://localhost:3000>, создайте канал и следуйте подсказкам в панели:

1. Ссылку **для зрителей** (`/c/<id>`) киньте в чат или описание стрима.
2. Ссылку **оверлея** (`/overlay/<id>?key=…`) добавьте в OBS как источник «Браузер» (1920×1080). Не показывайте её на стриме.
3. Нажмите «Тестовый алерт» — мем должен появиться в OBS.

Зрители могут отправлять мемы, только пока оверлей открыт (то есть пока идёт стрим).

## Бесплатный хостинг

Подойдёт любой хостинг с Node.js. Для [Render](https://render.com) в репозитории есть `render.yaml`: New → Blueprint → выберите этот репозиторий. На бесплатном тарифе сервис засыпает без посетителей и просыпается за ~минуту.

Переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт (по умолчанию 3000) |
| `SERVER_SECRET` | Секрет, из которого выводятся ключи каналов. Задайте постоянное значение, чтобы ссылки стримеров переживали перезапуск |
| `TRUST_PROXY` | `1`, если сервер стоит за прокси хостинга (IP зрителя берётся из `X-Forwarded-For`) |
| `DATA_DIR` | Папка для настроек каналов (по умолчанию `./data`) |

Настройки канала дополнительно хранятся в браузере стримера и восстанавливаются, если сервер их потерял.

## Как устроено

- `server.js` — HTTP-сервер: API, прокси поиска Coub с кэшем, рассылка событий через Server-Sent Events.
- `public/` — главная, панель стримера, страница зрителя, оверлей.

Проект не связан с Coub и MemeAlerts. Контент мемов принадлежит их авторам.
